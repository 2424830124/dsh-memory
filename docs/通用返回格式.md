# 通用返回格式

`memory_read` 读一个记忆文件时返回的文本长这样。占位符 `<...>` 是待填的内容。

## 整个文件

```text
---
file_name: <file_name>
desc: <desc>
scope: <scope>
---

# <t1>
- Keyword: <keyword>
- Update at: <time>
<desc>

## <t2>
- Keyword: <keyword>
- Update at: <time>
<desc>

### <t3>
- Keyword: <keyword>
- Update at: <time>
<desc>
```

## 读某一个标题

给 `heading_path` 就只返回那一棵子树，头部照旧是 `file_name` / `desc` / `scope`：

```text
---
file_name: <file_name>
desc: <desc>
scope: <scope>
---

## <t2>
- Keyword: <keyword>
- Update at: <time>
<desc>
```

## 读文件清单

不给 `file_name` 时返回清单，每行一个文件，缩进的那行是它的 `desc`：

```text
- <file_name> [<scope>]
  <desc>
```

一个文件都没有时是「（还没有任何记忆文件）」。

## 几点约定

- **头部带 `scope`**：同一个文件名可以在全局和工作区各有一份，去掉它模型就分不清改的是哪一份。
- **`- Keyword:` / `- Update at:` 都带前缀**：这样它们永远不会被误当成正文。读取输出是模型抄 `old_string` 的来源，必须和编辑工具比对的内容逐字符一致，所以读取**不受 `inject_ignore` 影响**，永远给全文。
- 空字段不出行：`keyword` 为空就没有 `- Keyword:` 那行，`desc` 为空就没有正文。
- 读日志的形状不一样，见[日志返回格式](日志返回格式.md)。
